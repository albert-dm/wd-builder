# Pi Harness for Webdrops Monorepo

## Problem Statement

Create a project-local pi harness that brings the existing Copilot instructions into pi-native resources and extends them with the team's target architecture, preferred stacks, TDD workflow, documentation discipline, and planning/execution process.

## Chosen Approach

Implement a lightweight but opinionated project harness with:

- `AGENTS.md` for always-on repo and architecture guidance
- project-local skills in `.pi/skills/` for repeatable workflows
- project-local prompt templates in `.pi/prompts/` for common task entrypoints
- a root `TODO.md` template/process anchor for task tracking

## Affected Areas

- `AGENTS.md`
- `.pi/skills/**`
- `.pi/prompts/**`
- `TODO.md`

## In Scope

- Migrate key monorepo guidance from `.github/copilot-instructions.md` into pi-native context
- Add new architecture guidance for TanStack Start apps, Hono services, Zod, Drizzle, OpenAPI, CSS Modules, clean architecture, and core package boundaries
- Encode the preferred workflow: Research -> Plan -> Execute, with Context7, graphify, TDD, docs updates, and todo maintenance
- Add prompts for common workflows like planning, feature work, review, and verification

## Out of Scope

- Building pi extensions
- Changing application code
- Generating a graphify artifact for the repo right now
- Adding automation outside pi resource files

## Options Considered

| Option                    | Pros                                                   | Cons                                       |
| ------------------------- | ------------------------------------------------------ | ------------------------------------------ |
| AGENTS only               | Simple, always loaded                                  | Too much instruction density, poor reuse   |
| AGENTS + prompts          | Good explicit entrypoints                              | Weak on reusable autonomous workflows      |
| AGENTS + skills + prompts | Best fit for always-on context plus reusable workflows | More files to maintain                     |
| Full extensions package   | Most powerful                                          | Premature complexity for current repo size |

## Recommended Path

Use `AGENTS.md` + focused project skills + prompt templates. This gives strong default behavior without extension complexity and aligns with pi's native resource model.

## Validation Plan

- Ensure files are placed in pi auto-discovery locations
- Review generated files for consistency with repo structure and stated stack choices
- Confirm naming/descriptions are clear enough for skill auto-selection
